# 💰 **Dashboard Financeiro**

Esse poderia ser um dos projetos mais profissionais do seu portfólio.

### Imagine algo parecido com:

```
┌──────────────────────────────────────────────┐
│ Logo                         👤 Ernand       │
├───────────┬──────────────────────────────────┤
│ Dashboard │                                  │
│ Entradas  │  Saldo disponível                │
│ Saídas    │  R$ 4.250,00                     │
│ Relatórios│                                  │
│           │  Entradas     Saídas             │
│           │  R$ 5.000     R$ 750             │
│           │                                  │
│           │  ┌─────────────────────────┐     │
│           │  │      gráfico            │     │
│           │  └─────────────────────────┘     │
│           │                                  │
│           │  Últimas transações              │
└───────────┴──────────────────────────────────┘
```

### Funcionalidades

- Adicionar receita
- Adicionar despesa
- Editar transação
- Excluir transação
- Categorias
- Filtros
- Cálculo automático do saldo
- Histórico
- Dashboard
- Persistência com localStorage

### TypeScript entraria bastante

 **Você poderia criar tipos como:**
```
interface Transaction {
  id: number;
  description: string;
  amount: number;
  type: "income" | "expense";
  category: string;
  date: string;
}
```

E trabalhar com esses dados de maneira tipada.
